Domain model

Evidence and relationships

Decision ↔ Evidence

A durable decision links to sources, affected files and downstream changes.

Claim ↔ Contradiction

Competing evidence remains visible with timestamps and confidence.

Memory ↔ Scope

Every result and neighbor traversal checks tenant, project and visibility.

Policy ↔ Description

Graph may describe policy provenance, but registry alone authorizes effects.

Failure design

Bounded graph snapshots

Graph queries use explicit scope, limits, revisions and cache invalidation. An unavailable graph may cause JIT retrieval to abstain; it must not weaken a trusted authorization decision.

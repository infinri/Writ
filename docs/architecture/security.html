Trusted base

What can grant authority

Kernel and signed policy

Pure authorization, hard-deny precedence and verified policy provenance.

Capability broker

Actually mediates the side effect, with idempotency and effect receipts.

Human approval channel

Authenticated human principal; exact scope, one-use grant and revocation.

Untrusted sources

Model outputs, retrieved documents, session transcripts, shell strings and graph values.

Profiles

Do not confuse hook denial with sandboxing

A hook-integrated profile mediates only the host events it actually intercepts. A broker-enforced profile requires declared effects to execute through a controlled capability path or independently verified sandbox.

Language

Rust is provisional, not settled

Rust offers fine-grained memory/resource control and mature native Cedar/Wasmtime integration. Go offers a straightforward concurrency/deployment model and supported Neo4j integration. Run identical workloads, consider developer experience and operations cost, then record a decision.

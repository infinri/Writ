System design

One authority. Separate intelligence.

Guiding boundaries

The four decisions that define V2

One broker

Tool effects are authorized and performed through one verified capability boundary, not contradictory hook scripts.

Signed policy

Immutable, versioned rules evaluate normalized actions; hard denials cannot become asks after retries.

Authenticated approval

Human grants bind an exact operation, canonical resource, content digest, principal, version and expiry.

Graph intelligence

Neo4j and Recall deliver evidence, linked decisions and scoped knowledge, not permissions.

Starting point

Clean rebuild, not a language translation

The current branch is documentation-only. Existing V1 Python and Bash code remains as reference material. The kernel language is subject to a Rust-versus-Go benchmark, while WASM, Temporal, Redis and Kubernetes remain optional later additions.

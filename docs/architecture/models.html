Models and agent hosts are independent

Writ can integrate with an external agent without touching its model calls—or optionally host a generic AgentRunner using a ModelAdapter.

Two integration modes

Existing agent or managed agent

External agent host

Claude Code initially; other supported hosts later. Writ receives normalized events, supplies memory and mediates declared effects. No Writ model credentials required.

Optional Writ-managed AgentRunner

ModelAdapter handles provider inference; AgentRunner handles planning and budgets; kernel and broker remain independent of model behavior.
